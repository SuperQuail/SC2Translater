> ✅ **P0 已完成**：文件访问接上了真实入口 —— 「打开…」会选文件夹、读/建工作区、

下面这段是当初的问题描述，留作记录：

> ~~文件访问的数据层与界面都写好了，但在真机上没有任何入口能触发它。~~

`scan_folder` / `open_file` 目前只有深链 `?file=` / `?folder=` 会调；
`ExplorerPane` 的「工程文件」树因此**在真机上永远是空的**，点也点不开任何文件。
根因是本工具还没有「工程 = 一个文件夹」这个概念 —— 它现在只有「一个 .sc2transproj 文件」。

所以待办的第一优先级不是加功能，是**把工作区改造做完**，让文件访问接上真实入口。

## P3 明确不做（别再提）

* 多根工作区（VS Code 的 `.code-workspace`）—— 单文件夹够用；
* 在资源管理器里新建 / 删除 / 重命名文件 —— 那是用户的游戏目录；
* 二进制十六进制预览 —— 用不上，且容易被误当成「可以改」；
* 完整的文本编辑器（高亮 / 多光标 / LSP）；
* 远端仓库（我们本来就没有远端）。
