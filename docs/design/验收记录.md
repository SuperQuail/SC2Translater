## 5. 银河编辑器验收（**关键**）

装置：上游 SC2Diff 的 " + B + "tools/editor_accept.py" + B + "（无参启动编辑器 -> 文件/打开 ->
按模块窗口标题判定，崩溃则以 EditorLogs 新增 Error 目录为证）。**同目录放了未改动的原件作对照。**

    python D:\Code\Rust\SC2Diff\tools\editor_accept.py \
      testdata\acceptance\aa_original.SC2Map \
      testdata\acceptance\bb_all_filled.SC2Map \
      testdata\acceptance\cc_zhCN_only.SC2Map

原始输出（节选）：

    DOC ...\aa_original.SC2Map (902586 bytes)
      state=loaded  VERDICT: LOADED
    DOC ...\bb_all_filled.SC2Map (1059752 bytes)
      state=loaded  VERDICT: LOADED
    DOC ...\cc_zhCN_only.SC2Map (878025 bytes)
      state=loaded  VERDICT: LOADED

    {"aa_original.SC2Map": "LOADED", "bb_all_filled.SC2Map": "LOADED", "cc_zhCN_only.SC2Map": "LOADED"}

**三个全部 LOADED**，其中两个是本工具产物 —— 容器改动被编辑器接受，未崩溃。

> 关键前置：写入时 " + B + "dwRawChunkSize" + B + " 必须为 0。暴雪原件在这个字段写的是 16384，
> 那会打开 System_Mopaq 的 raw-chunk MD5 校验，导致**任何**内容改动都被判 " + B + "e_fileCorrupt" + B + "。
